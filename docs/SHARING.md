# 行知助手 · 0.42.4 源码与 0.40.0 安装说明

把信息交给助手，自动整理为事项，持续推进、跟进结果，再检查与验收。

当前公开源码版本为 **0.42.4**。本次仅更新源码，不创建新的 GitHub Release 或发行资产；现有 [latest 安装包](https://github.com/lkj110/xingzhi-assistant/releases/latest) 仍为 **0.40.0**，不是 0.42.4 下载。私有最终包与本公开源码分别验证和记录身份，不互相代替。

以下安装步骤针对现有 0.40.0 包；新源码能力与信任策略见 [使用说明](USER_GUIDE.md)，不能假定旧安装包包含这些能力。公共正式打包缺少私有历史合同/证据时会明确失败，见 [公共测试边界](PUBLIC-TESTING.md)。

## 安装现有 0.40.0 包

适用：Apple Silicon Mac（M1、M2、M3、M4 及更新芯片），macOS 13 或更高版本。本包不适用于 Intel Mac 或 Windows。

1. 打开 `Xingzhi-0.40.0-macOS-arm64.dmg`，把「行知助手.app」拖到「Applications」文件夹。
2. 从「应用程序」打开「行知助手」。如果用 ZIP，先解压，再将 App 移入「应用程序」。
3. 旧版还在菜单栏运行时，先从菜单栏退出旧版，再安装和打开新版。

现有 0.40.0 安装包是个人分享版：做了本地完整性签名，尚无 Apple Developer ID 签名和 Apple 公证。macOS 首次打开可能拦截。确认安装包来自可信发送者后，先尝试打开，再进入「系统设置 → 隐私与安全性 → 仍要打开」。受公司管理的电脑可能需要 IT 允许。详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

如系统提示文件损坏或恶意软件，请先停止安装、重新获取安装包并与发送者核对校验值。

若使用 0.42.4 源码构建的版本，在能力中心确认过 DW 脚本信任策略的工作空间，不支持直接用 0.42.3 或更旧版本打开：旧版不识别新的执行保护。出现问题时应保留数据并使用仍包含该保护的修复版，不要用旧快照覆盖新权限、费用或执行历史。本说明不表示已替你安装新版。

## 第一次打开

App 会显示快速上手弹窗，按连接模型、记录目标、Agent 推进、成果验收四步开始。顶部「使用说明」提供完整离线手册、关键词搜索、下载和重新打开上手引导；macOS「帮助」菜单也可进入。安装包另附《完整使用说明.md》。

## 导航入口

左侧保留工作台、待我处理、Agent 委托、信息收集、项目、工作产出。点击后，在页面上方切换相关功能；全局检索和模型与设置位于底部。

- 自动获取办公消息、网页与文件：信息收集 → 信息连接。
- 查看自动触发规则与复用方案：Agent 委托 → 工作规则 / 工作方案。
- 查看运行、用量与备份：模型与设置 → 运行与恢复。
- 已完成、已暂停及需要关注的事项：工作台 → 工作看板中的状态筛选。

## 配置自己的模型

应用不附带发送者的账号、API Key、模型额度或工作资料。首次启动是新的工作空间。

在「模型与设置」选择一种方式：

- **国内与开源模型**：选择 DeepSeek、Kimi、千问、GLM、MiniMax、豆包或硅基流动预设，填写自己的密钥，读取列表或手动填写模型 ID。
- **国际模型**：选择 OpenAI、Claude、Gemini、Azure、Grok 或 Mistral，也可使用 OpenRouter、Groq、Together AI。
- **自定义接口**：支持 Chat Completions、Responses、Anthropic Messages、Gemini 和 Ollama 协议，可修改服务地址、鉴权方式和生成参数。
- **ChatGPT 订阅（Codex CLI）**：需要本机已安装、可被应用检测到的官方 Codex CLI，并已用自己的 ChatGPT 账号登录。点击「检测登录」，确认可用模型后保存。只有网页登录 ChatGPT 并不代表本机 CLI 已登录。如果检测不到 CLI，可先使用兼容接口，或联系发送者协助配置 CLI。
- **本地开源模型**：需要另行安装并启动 Ollama、LM Studio、vLLM、SGLang 或 llama.cpp，加载模型后填写服务地址和实际模型名。

分别为「信息整理」「事项推进」「结果检查」选择模型。第一份配置默认用于三个角色。模型能力和服务可用性会影响执行结果；订阅调用占用接收者自己的额度，API 按接收者所选服务计费。

## 开始第一项工作

1. 打开「项目 → 新建托管项目」，填写目标，例如「收集项目进展，列出待办，整理带来源的周报」。
2. 粘贴一份材料，可选添加 RSS、公开网页或明确授权的本地资料目录。
3. 检查配置预览。首次可以创建为暂停；确认模型和资料范围后再启用规则及信息连接。
4. 从「工作台」查看执行进度，在「待我处理 → 待我决策」补充信息或确认，在「待我处理 → 成果验收」检查结果。

通过「快速收集」可继续添加文字、PDF、DOCX、文本和图片。PNG/JPEG 与扫描 PDF 在本机识别；PDF 每份最多 10 MB、总计 250 页，其中需识别的无文字页最多 20 页。同一页既有文字又有图片时，只提取已有文字并提示图中文字未另行识别。

## 数据与运行

- 工作数据保存在接收者自己的 Mac，通常位于 `~/Library/Application Support/行知助手/workspace`。设置中可查看位置并创建备份。
- 相关材料文字、反馈和产出会在推进时发送给接收者配置的模型服务。API Key 使用系统钥匙串加密存储；工作材料自身保存在本机明文文件中。
- 资料目录、产出目录、GitHub 和飞书等连接需要各自配置和授权。分享 App 不会带来发送者的授权。
- 关闭主窗口后可留在菜单栏运行。退出应用、关机或休眠时停止推进；持续托管需要应用运行、电脑唤醒及网络和模型可用。
- 更换版本前建议备份。拖走或删除 App 不会自动删除工作数据。

## 反馈问题

请提供「帮助与说明」显示的应用版本、macOS 版本、芯片型号、操作步骤和错误提示。可从「模型与设置 → 工作体检」导出摘要。分享截图前请遮住工作内容和个人信息，不要发送 API Key 或整个工作空间。

安装包旁的 `SHA256SUMS.txt` 可用于核对下载文件。DMG 与 ZIP 内含相同应用，任选一种使用。

## 截图与聊天工具接入

在“收集信息”或快速收集小窗中框选截图、粘贴截图，再点击“识别并转事项”。OCR 在本机执行，整理时只将识别文字交给你配置的模型。

在“信息连接 → 办公与聊天信息入口”中配置企业微信 Bot ID/Secret 或钉钉 Client ID/Secret，选择项目并启用。机器人接收发给它的新消息，不读取完整聊天历史；退出或休眠期间无法保证消息补发。需要在对应平台先创建并发布机器人。个人微信目前通过截图、复制文字或授权文件夹收集。

同时提供 Slack、Notion、Outlook 和通用 JSON 信息源。新连接默认停用，密钥需使用者自行配置，不包含在安装包内。

## 长任务与节省额度

模型配置里可分别填写「无新数据等待」与「总等待上限」，单位为分钟，0 表示不限时。默认总时长不限、无新数据等待 15 分钟；本机模型长时间思考时可延长或关闭该限制。

新建订阅配置优先选择 CLI 缓存中的日常经济模型，推理强度默认 medium；整理、推进、检查可各选不同模型。订阅消耗额度，API 费用由服务商计费。临时错误可勾选一次重试，已配置备用时第二次使用备用模型；两者不叠加成更多尝试。

在事项详情的「长任务与已有成果」中选择按章节生成。目录与每个完整章节都保存到本机；中断后点击「从已保存章节继续」。仅完整章节成为保存点，未返回完整 JSON 的当前章节需要重试。修改要求或材料后会重新规划，旧章节可下载。默认自动模式下，精简与纯编辑优先一次完成；其他步骤上下文超过 14000 字符时启用分段，每步最多 8 节。

已在其他地方完成正文时，点击「使用已有成果」，导入 MD、TXT、CSV、JSON 文件或粘贴完整正文，然后「保存并继续推进」。每份正文最多 100000 字符。只替代当前文本步骤，外部动作仍需真实执行依据；所有步骤完成后进入模型检查，默认由你最终验收。

## 从已有事项交给 Agent

打开事项详情，点击「交给 Agent 继续」，补充新的要求、选择资料范围后启动。原事项 ID 和历史产出保留，Agent 会重新规划和推进。之后在同一位置点击「查看 Agent 委托」，可补充要求、查看运行记录与工具返回。项目事项继续在所属项目中委托。

## SG 数据平台只读查询

新建或转交委托时，勾选「允许读取 SG 数据平台」。需要本机安装官方 bytedcli，并已登录具有资源读取权限的账号。Agent 可查询本人任务、项目列表、任务上下游、SQL 与 Coral 表元数据；不能修改任务或执行 SQL。查询结果保留为本地材料，可以追溯。长结果按来源分段读取，分页和深度边界不等于已取得全部数据。跨区域和无权限资源需在结果中注明。

## 推进用量与费用上限

在「Agent 委托 → 委托详情」或「事项详情」查看「推进用量与额度」。运行记录显示每轮输入、缓存输入、输出及总 token；「模型与设置 → 最近模型调用」显示每次请求的模型、用量、单价和折算费用。

同一委托及其事项共用默认 **100 美元等值额度**；独立事项单独累计。分段生成、自动续跑、重试、备用模型和结果检查都会累计；暂停、重启、反馈修改、恢复章节和恢复旧备份不会重置额度。

接近上限时，应用会先检查下一次请求的预留额度。不能容纳或已经达到上限时停止后续推进。需要你点击「追加 $100 等值额度…」，核对后再点击「确认追加 $100」。增加调用次数不能替代这项确认。用量缺失时保留预留金额，只要原额度足够就继续，不逐笔要求确认；未配置价格的模型须先填写单价。

订阅费用按模型参考价格折算，用于应用内控制，**不代表实际扣费或剩余订阅额度**。第三方服务请在模型配置中填写输入、缓存输入及输出单价。每次请求结束后才有服务商报告，单次请求可能超出预估；结算后停止后续调用。升级前缺失或已裁剪的记录不能准确补算，会明确提示。

外部搜索、办公服务和存储的独立费用不计入模型 token 预算。

缺失用量但已有预留时，保留预留并在原额度内继续，不再要求逐笔知悉。只有旧记录既缺少用量又没有费用预留时，需要核对历史消耗；这不等于已经超出 $100。

选中文字的微型弹窗和 ⌘⇧2 框选截图入口默认开启。首次引导会提示辅助功能和屏幕录制权限，授权后自动检测；可在模型设置关闭。
