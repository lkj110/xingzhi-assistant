# 行知助手 Windows 基础核验版

交付范围固定为：导入资料 → 按要求生成文稿 → 独立证据核验 → 人工验收。基础版本号保持 0.42.4；本分支 `codex/stable-foundation` 和交付清单标识具体构建。A–D 实验仍在 `codex/shared-evidence-core`，不属于本版验收范围。

## 使用约定

在“模型与设置”中开启严格证据核验，关闭自动托管和自动完成。先添加原始材料，再创建事项并写明完成标准。一次只推进一个需要交付的事项，阅读文稿与核验结果后手动验收。若证据缺失、冲突未解释或核验未完成，保留原稿并补充材料，不把“待核验”当作已完成。

安装后需核对严格核验开启、自动托管和自动完成关闭；新工作空间同样需要核对。本版没有改变历史实现的默认值。外部发布、完整 Agent 自动执行、跨平台打包及 A–D 的新能力未取得本次交付认证。

## 效果依据

历史 J 对照于 2026-10-22 执行，模型为 gpt-6.1-sol / medium，两组均开启严格核验，比的是核验输入 v1 与 v2，**不是“关闭核验与开启核验”的对比**。共 20 对题目：16 对固定稿、4 对现场生成稿，每版 44 次应用调用。

| 指标 | 比较基线 | 本版实现 |
|---|---:|---:|
| 合格固定稿通过 | 8/8 | 8/8 |
| 不合格固定稿被拦截 | 8/8 | 8/8 |
| 固定稿误拦率 | 0/8 | 0/8 |
| 固定稿错误放行率 | 0/8 | 0/8 |
| 生成稿到达待人工验收 | 4/4 | 4/4 |
| 已交付到待验收的生成稿含幻觉 | 0/4 | 0/4 |
| 生成稿误拦率 | 0/4 | 0/4 |
| 生成稿错误放行率 | 不适用（0 个不合格生成稿） | 不适用（0 个不合格生成稿） |
| 输入 tokens（已含缓存） | 612,830 | 606,647 |
| 输出 tokens | 19,983 | 19,792 |
| 总 tokens | 632,813 | 626,439 |

总量减少 6,374 tokens，约 **1.007%**。本版 626,439 tokens 中，生成阶段 105,968（8 次调用），核验阶段 520,471（36 次调用，约 83.08%）。固定稿核验每题平均 28,649.25 tokens；生成加核验每题平均 42,012.75 tokens，仅描述这批工作量，不能当作新任务的报价或保证。缓存输入不重复计入总量；订阅调用的 tokens 不是现金账单。

这批实验只证明到达 `review`（待人工验收），没有在线运行人工 accept 或完整 Agent 闭环。不合格固定稿中也包括如实披露未知、但未满足唯一确认要求的稿件，不能把所有不合格都称为幻觉。

独立审核对照了 839 个历史文件、189 个评测桌面模块、88 次调用、232 处原文引用及实际最终稿。32 份固定稿未被修稿替换，8 份生成稿与原始响应一致。旧审核由实现者完成，本次是事后非盲复核。少量合成题不证明总体零幻觉，也不证明今天的在线服务可用性。

## 交付验证和边界

本日验证记录与安装包身份由单独的交付报告记录；不能把尚未完成的检查当作通过。全量 Windows 测试首次运行因 Python 启动器及 TEMP 短路径问题停止，保留失败日志；归一化测试环境后重新执行。未为获得通过而修改产品语义。

离线模型替身用于验证文稿、核验、人工验收及重启持久化，不能代替新的真实模型评测。本次交付不新增真实模型调用，不启动正式主评测，不复用已停止实验的剩余额度。

后续只接收影响上述交付范围的阻断缺陷。若需要扩大保证范围，应先固定新范围、样本、通过条件和预算，再开独立版本；不把 A–D 持续追加到本版。
