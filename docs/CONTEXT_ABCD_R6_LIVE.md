## 下一步：先修两处协议问题，再整理输入

1. **分离历史观察证据与当前状态新鲜度。** `action_status` 的动态回执统一 60 秒过期。文件题第一次观察到下一次 worker 调用发出相隔 84.6 秒，回执被滤掉；第二次观察到核验调用发出相隔 72.2 秒，再次消失。应保存带时间、文件哈希和权限范围的“该时点观察事实”，同时保留“现在是否仍一致”的新鲜度检查。过期或变化不得被包装为当前状态已证实。离线用可控时钟覆盖慢调用、文件变化、权限撤回与重启。
2. **将标题字段与正文 H1 的修订语义说清并一起校验。** 当前提示“标题修改放在 title 字段，不能当作正文 edits”，而正文 H1 独立存在。两次模型响应都只改标题字段，补丁执行器按片段执行后保留了旧 H1。协议歧义已确认，不能只归咎模型漏改。修复需同时覆盖元数据标题、正文标题及完整章节的一致性，继续保留独立核验。
3. **整理当前要求与历史要求的关系。** 旧委派目标 M1/P1 仍进入当前 agreement 清单，同义修订指令也重复出现。应明确被替代要求及继承要求，保留可审计历史；本轮证据不能证明旧目标导致了两次拦截，不能把它当作已证实根因。
4. **再优化整体核验的首轮证据包。** 为当前有效要求提供最小而完整、可回查的原文与必要例外，减少补读往返；保持独立判断，继续用真实 usage 衡量总成本。
