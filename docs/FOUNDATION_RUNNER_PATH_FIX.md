# 冻结基础版评测执行器：Windows路径修复

日期：2026-10-28。修复范围仅为评测执行器；Foundation 0.42.4产品源码、已安装EXE/ASAR、六例样本、金标准及语义核验协议均保持冻结。本阶段真实模型调用为0，未运行官方模型CLI登录探针。

## 改动

上轮请求在推理转发前失败：Node保留的Windows短路径与.NET报告的长路径属于同一个目录，执行器却按路径字符串判为越界。现在用native realpath解析两种拼写，并核对目录及文件的dev/ino身份。原始CLI参数、模型输入和输出schema保持原样。

路径校验单独放在 `evaluations/foundation-runner/paths.cjs`。工作目录必须是临时根的直接子目录；schema和输出必须位于该目录，叶名固定为schema.json和response.json。分发前重核目录、schema身份及内容，并确认输出尚不存在；读取结果与保存原始响应前再核验，拒绝已观测的链接、硬链接、目录换址或文件替换。它不是对同权限进程并发恶意修改的原子防护保证。

成功与拒绝回执均保留原始路径、规范化路径和存在状态；拒绝另有稳定错误码、业务处理阶段及路径校验阶段。路径诊断不包含完整命令参数、环境、nonce或提示词。准入之后、实际执行之前发生拒绝时，仍只计一次应用尝试，并明确用量为“已证明未分发的0”，不伪造provider usage。真正转发后用量未知的停止规则不变。

新增路径集成驱动在两个独立Node进程中设置真实等价的短/长TEMP，每个运行原有五项安装包集成场景。短路径不可用时明确失败，不静默跳过。原有证据绑定、语义标准、请求协议、预算、一次性授权和人工接受边界保持不变。
