# 模型选择与每轮费用（v0.24.13）

在「Agent 委托 → 委托详情 → 运行记录」，每条记录默认显示本轮使用的模型、总 token 和折算费用。展开记录，再展开「逐次调用」，可查看每个请求的模型、用途、选模原因、输入/缓存/输出用量和当时记录的单价。

自动选模启用后，选择下一步工具与调度优先使用日常模型；当前步骤是精简、改写、格式整理已有内容时也优先使用日常模型。实际血缘、根因、依赖或多来源分析与复杂结果检查使用分析模型。当前步骤同时要求核验事实、分析矛盾时保留分析档。单事项委托的工具调度沿用该事项的手动模型偏好。模型来自用户已保存并选定的两档配置，费用上限和故障接续规则继续生效。

费用来自历史调用记录，包含本轮内的生成、检查、重试与故障接续。历史不会按当前模型或单价改写。含未知用量时只展示已知费用，并标出缺口；没有单价时显示待计价；旧记录没有用量时显示未记录。额度预留显示在全过程额度区，不能当作实测费用。

订阅模型的美元值是参考单价折算，不等于订阅实际扣款。输入、缓存输入和输出分别计算；记录包含长上下文规则或缓存写入时，逐次详情说明相应倍率。
