# v0.40.0 — 首次公开开源版本

完整行知助手桌面应用以 MIT 许可证公开，包含 React 界面、Electron 后台、Swift 本地助手、测试与构建脚本。

## 多模型接入

新增 DeepSeek、Kimi、千问、GLM、MiniMax、豆包、硅基流动等预设；支持 Responses、Claude Messages、Gemini、Azure、OpenAI 兼容接口与 Ollama。共 23 个预设，可读取模型列表、填写任意模型 ID，并配置鉴权、输出上限与模型参数。

## 开源整理

- 提供安装、源码运行、贡献和安全说明，以及 MIT 许可证。
- 测试中的业务编号和表名替换为合成样例，保留原断言和边界覆盖。
- 工作空间、凭据、历史业务审计、构建产物与依赖不进入 Git 历史。
- 保留完整应用与可选连接器；企业专用平台需要使用者自己的客户端和权限。

## 验证范围

发布基线已通过 2,646 项本地回归、116 项最终模型/费用专项、七组新增模型桌面流程，以及 DMG/ZIP 签名、解压、运行文件一致性和隔离启动验证。公开副本会重新执行构建与测试，结果以 GitHub Actions 和发布记录为准。

桌面和协议测试使用本地模拟服务，不代表每个厂商账号均已实测。曾有一次备用接续桌面场景在启动引导步骤超时，独立重跑通过。

当前安装包目标是 Apple Silicon Mac、macOS 13+。采用 ad-hoc 签名，未公证；其他平台、真实系统权限交互与每种外部服务组合不在本次验证范围。
