# 严格核验的上下文实现（候选 v4）

本次候选按 A→B→C→D 实现。是否上线、成本和质量结果以工作区 `outputs` 中的真实对照报告及运行加载核对为准；本文件不代表验收通过。

- A：在实际选定模型的 transport 前统一预算，已知窗口减去输出和包装预留；未知能力显示保守回退。最终发送成功的同模型范围才进入核验可见集。超限恢复最多一次，必须比上一请求更小；有界最终核验不重试。稳定字段排序保留原文和语义数组顺序，相关小资料可完整预取。
- B：同轮生成维护要求取证计划，完成读取会消费请求，部分读取保留 canonical 续读位置。新增 `search_evidence` 做本地向量＋字面融合，保留原 `search_source`。证据组扩展完整段落/表格、邻段、章节、脚注和明确交叉引用；未定位引用或输入裁剪均不能标记完整。检索异步后复核授权和来源版本。
- C：`compute_evidence` 仅支持白名单确定性运算和已有动作的只读回读，参数绑定授权原文。回执绑定输入、操作、输出、哈希和有效条件；动态状态不能用旧成功记录自动续期。事实记忆区分来源、可回查的用户陈述与来源不明，旧值及迁移记录保留。
- D：现有独立 checker 完整核验当前稿，附 `consistencyIssues`，绑定现有结论与两处当前正文锚点。C/D 开关及证据有效状态进入核验依据；旧通过记录不授权新稿交付。

协议为 `grounding v4 / compact-v4 / verify-input-v3`。用户仍只有一个严格核验开关；内部 `contextOptimizationOverrides.A/B/C/D` 只用于受控测试和回退。

本地语义运行库固定 `@huggingface/transformers@3.8.1`；模型为 `Xenova/paraphrase-multilingual-MiniLM-L12-v2`，revision `2c4055b12046f11709e9df2c122e59ffbdc2f900`。Windows 使用 WASM CPU。`scripts/install-evidence-encoder.cjs` 安装固定资源；`resources/evidence-encoder/manifest.json` 记录文件 SHA，运行前校验并禁止远程模型加载。资源缺失明确降级为字面检索，不当作语义验收完成。模型 Apache-2.0 许可证随资源保存；索引是可重建内存缓存，按任务/授权/来源版本隔离。

DOCX 仅恢复可读取的段落、表格行和脚注，PDF/OCR 仍保留结构警告。不能把无法恢复的版面关系视作已证实。预算 UTF-8 上界是保守估算，CLI 隐藏包装不可精确计数；真实成本以供应商 usage 为准。

回滚保留前一源码和依赖快照；不得覆盖用户工作区或恢复旧核验授权。实际应用只在空闲时正常重启，通过默认工作区 IPC 的加载时哈希、协议和 UI 资源确认生效。
