# 工作空间导航

v0.24.12 将侧栏的 26 个入口合并为 6 个主入口和 2 个工具入口。页面上方展示当前分组的二级导航；功能页和业务数据保持原有对应关系。

| 左侧入口 | 页面内的入口 |
| --- | --- |
| 工作台 | 工作看板、今日安排、工作简报、推进记录 |
| 待我处理 | 待我决策、成果验收、关注提醒 |
| Agent 委托 | 委托列表、工作规则、工作方案 |
| 信息收集 | 信息收件箱、信息连接、收集队列、材料归类 |
| 项目 | 全部项目、工作地图、工作记忆 |
| 工作产出 | 每个事项的当前成果与历史版本 |
| 全局检索 | 检索材料、事项、成果及过往决定 |
| 模型与设置 | 模型配置、运行与恢复、工作体检 |

“已完成事项”“已暂停事项”“需要关注”使用工作看板中的状态筛选。“待我验收”合并到“待我处理 → 成果验收”；看板仍可按待验收状态筛选。

从成果、关注提醒、项目或系统通知直接进入功能时，左侧分组与页面内的当前入口会同步高亮。快速收集保留在右上角。
