# 主动收集、微型弹窗和仓库能力（v0.26.0）

## 主动收集

打开 **信息收集 → 信息连接 → 配置主动收集**。填写项目目标、预期结果，选择飞书文档/会话、公开网页、RSS 或授权本地目录；设置关键词、检查间隔及允许的扩展能力。检查预览后选择“创建后启用资料收集和推进规则”并保存。

同一项目的后续材料复用原事项与委托。有来源变化才触发推进；规则、全局暂停、运行时段及原有额度仍有效。飞书依赖本机 lark-cli 登录。向导不自动读取整个聊天软件，也不自动订阅未指定来源。选择暂停创建时，各资料入口与规则都保持暂停。

## 微型弹窗

在 **信息连接** 或 **模型与设置 → 模型配置 → 桌面快速收集** 中设置：

- **选中文字后显示微型记录弹窗**：开启后，在 macOS 系统设置的“隐私与安全性 → 辅助功能”中允许行知助手。鼠标选中文字后会显示预览，点击“补充目标与预期结果”展开。部分应用不提供可读选区，此时复制并主动粘贴到小窗。
- **截图快捷入口 ⌘⇧2**：开启后按快捷键框选，完成后截图带入小窗。首次使用可能需要系统屏幕录制权限。系统自带截图仍通过复制后粘贴导入。
- **⌘⇧空格**：开启全局快捷键后，随时打开快速记录窗口，也可从应用菜单/托盘进入。

填写“希望推进什么”和“预期结果与推进要求”，选择可用能力后点 **记录并推进**。先持久保存材料和要求，再建立事项、交给 Agent。指定已有项目时沿用原委托及其累计额度；暂停的原委托需要在工作台恢复。最终结果等待验收。

选区只在本机预览；提交前不会交给模型。不会持续读取剪贴板。自动选区弹窗不覆盖已有草稿；截图捕获遇到已有草稿时提供“加入当前草稿”。未提交草稿在退出应用时清除，已入队的材料可在收集队列重试。

## 能力中心

打开 **模型与设置 → 能力中心**。点击“添加仓库”，可重复添加多个 DW、Skills 或 Agent 文档仓库，并命名、搜索、编辑、停用、移除或恢复。选择本地目录和版本更新方式，点“检查能力”再“挂载所选能力”。通用仓库提供 Markdown 技能文档读取，DW 自动添加静态检查工具。在新委托、快速记录、主动收集向导或工作规则中选择授权。已有独立委托的“扩展能力”卡片可更新授权。

本轮 DW 适配覆盖：

- `list_skills`：列出技能、协议与知识文档。
- `read_document`：分页读取登记文档。
- `sql_review`：执行仓库的 Hive/Spark SQL 静态检查器。
- `python_review`：执行仓库的 PySpark 静态检查器。

每次调用前自动获取最新内容：默认扫描本地目录，包含未提交修改；也可选择跟随 Git 远端分支，使用独立缓存中的最新提交，不改动源目录。远端模式需要本机 Git 和登录，无法更新时本次调用失败，不使用旧缓存。仓库数量不设上限，每个委托最多选择 10 项。

版本、文档或脚本内容更新且工具接口不变时沿用原授权。来源、更新方式、已选工具范围或接口变化后需重新授权；新增工具不会自动获得权限。最近调用显示实际版本、提交号、内容指纹及本地修改标记，检查结果与版本保存在本委托材料。静态检查不等于生产验证；Python 隔离运行不加载可选 sqlglot 增强。

也可挂载 **本地 MCP stdio**：填写已安装程序的绝对路径、JSON 参数数组和运行目录，检查后勾选工具。第一版只接入声明只读、且不另外调用收费模型的工具。工具声明不是系统沙箱；仅运行信任的本地仓库/服务。远端更新只读取文档和 DW 检查脚本，不执行安装、Git hooks 或子模块；没有自动安装远端仓库，不支持 HTTP MCP、独立收费 Agent、DW 完整多 Agent 编排、生产 SQL 执行或发布。

模型推理仍由 App 统一调用和计量，沿用模型选择规则和同一推进全过程的 $100 等值上限。DW 静态脚本不调用模型；MCP 服务须满足配置时确认的“不独立调用收费模型”约束，App 无法核验第三方服务内部的隐性计费。
