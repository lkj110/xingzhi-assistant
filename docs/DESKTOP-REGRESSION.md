# 桌面回归测试

测试入口：`npm run test:desktop`。需要本机安装依赖，以及 macOS 的 Swift / Vision / PDFKit（图片与扫描 PDF 场景使用真实本地 OCR）。

## 运行方式

- 全量：`npm run test:desktop`，先构建，再按固定场景清单串行执行。
- 已完成构建：`node scripts/run-desktop-regression.cjs`。
- 指定场景：`node scripts/run-desktop-regression.cjs quick-capture image-ocr parallel`。
- 单个脚本：`node scripts/quick-capture-desktop-smoke.cjs`。
- 自定义报告目录：设置 `DESKTOP_TEST_REPORT_DIR`。默认 `artifacts/desktop-regression/`。

每个场景启动独立 Electron 进程与临时数据目录。场景结束后删除临时业务资料，保留执行日志、最终状态 JSON、界面文字和截图。某套失败后继续执行其余套，最终以非零状态退出。超时会结束该测试的进程组，不会结束已安装 App。

## 统一 fixture 约定

| 文件 | 职责 |
| --- | --- |
| `scripts/desktop-scenarios.cjs` | 固定场景清单，不从 npm 命令反向解析，避免 runner 自递归。 |
| `scripts/run-desktop-regression.cjs` | 串行启动、每套日志、超时清理和汇总退出码。 |
| `scripts/desktop-test-support.cjs` | 要求临时 userData，等待主界面，按需关闭新手引导，关闭前收集证据；提供当前小窗辅助方法。 |
| `scripts/desktop-test-bootstrap.cjs` | 拦截 OS 选区监听、真实全局快捷键、系统通知与订阅 CLI；允许具体场景安装确定性的替身。 |
| `scripts/standard-desktop-fixture.cjs` | 加载真实主程序，使用可预测的订阅登录状态；仅在测试中显示已登录，不代表真实账号验证。 |
| 各 `*-fixture.cjs` | 每领域的材料、模型响应与连接器替身；业务处理仍通过真实 IPC 和产品后端。 |

要求：

1. 所有桌面脚本从 `desktop-test-support.cjs` 获取 `electron`，不得连接已安装 App 或真实工作空间。
2. 模型使用进程内替身或 `127.0.0.1` HTTP 服务。普通功能测试显式配置测试单价；费用专项保留其非零单价和用量断言。禁止调用真实付费模型。
3. 图片、PDF 使用测试生成的文件；截图按钮和粘贴事件使用固定图片，不读取用户剪贴板、不捕获真实屏幕。
4. 首次引导场景用 `assistantTestGuide:true`，明确验证引导；其他场景统一关闭引导，避免遮挡后续表单。
5. 小窗提交成功的契约是“持久入队后清稿并隐藏”。通过主工作台队列确认完成或失败，不要求已隐藏的小窗保留旧回执。新草稿不能被旧队列结果清除。
6. 不通过删除断言、捕获后忽略错误或缩短业务场景获得全绿。界面改版应更新入口，并保留保存、去重、范围隔离、恢复和验收断言。
7. 模型调用次数是统计值；不再测试已移除的全局每日调用上限。保留每批调度动作数、工作时段、原推进预算与暂停恢复检查。

## 不包含的验证

- 真实鼠标划词、Sublime/飞书等外部应用的辅助功能兼容性与系统权限弹窗。
- macOS 顶部菜单栏与 Dock 图标/数量的实际呈现。
- 真正的 OAuth 登录、外部平台权限、飞书/GitHub/办公工具网络可用性和付费模型质量。
- 安装、签名、公证、升级迁移包，以及 Windows / Intel Mac / 移动端兼容性。

这些测试验证 App 的 UI、IPC、业务控制和本地文件处理，不能替代上面的真实环境验收。

## 实际分享包验证

`npm run test:share` 直接验证 `release-share/v<版本>/` 中的 DMG/ZIP，并从解压后的 App 启动临时 profile，不安装、不调用真实模型、不读取当前用户工作空间。

它另外检查：归档 SHA-256、DMG 只读挂载、ZIP 权限/符号链接、原包严格签名、ASAR 内容与源码一致、三个原生助手签名及去签名后内容一致、首次引导、无模型快速保存、包内扫描 PDF OCR 与重载持久化。Zod 公共依赖内的 `tests` 项单独统计；其他测试目录仍拒绝。工作空间、凭据、`.env`、`.codex`、备份、收集暂存与 artifacts 保持全路径禁入。

实际包验证不会注入桌面 fixture。它不覆盖 Gatekeeper 首次下载批准、Apple Developer ID、公证或安装升级；报告应保留这些限制。
