本包只有一项独立协议门检和六项业务题。全部原文是新编合成历史记录，题内提供全部作答依据，不需要外部资料、宿主工具或现实业务操作。本包提供题面、独立正确答案、判分边界和可复核的原文锚点；尚未执行真实模型测试，也不证明产品已达到验收标准。六题属于有限能力抽查，不能据此主张总体统计效力。

## 出题隔离与文件职责

编题时仅读取了 `foundation-candidate-20261028/stimuli.json`、同目录 `plan.json` 以了解数据形状，以及 `foundation-acceptance-20261028/inputs.cjs` 以确认输入白名单。没有读取产品 grounding 实现、测试内容、旧 gold 或参考稿，也没有针对实现挑选有利措辞。新业务名、完整 case/gate ID 只用固定字面 `rg` 在 `evaluations/` 与 `tests/` 中查重，均无旧匹配。独立审题仅使用新题面的文字，主要消除了卡数/人数、签收/验收、记录封存/场地状态等潜在歧义。

- `stimuli.json`：六项业务的用户要求、短源、固定错误稿与预定生命周期。
- `gate.json`：单独门检完整输入及协议成功条件，供计划文件引用；门检不计入业务指标。
- `gold.json`：离线答案和人工判分点，包含 `FOUNDATION_CANDIDATE_GOLD_ONLY_` 前缀 canary；不得进入模型输入。
- `anchors.json`：所有 gold assertions 的原文锚点；同样不得进入模型输入。
- `inputs.cjs`：唯一初始输入投影，仅 title、加历史前缀的 description、criteria、sources 中 title/content，以及固定负例的 candidate。
- `preflight.cjs`：仅针对本包的离线结构、引文、UTF-16 锚点与白名单检查；不调用应用、不加载产品实现、不调用模型。

计划、包清单、密封哈希及真实执行授权由主任务另行创建。本包不创建或续用 live 授权。预算、rubric、参考答案、assertions、源键、工作流和 revision 不得混入初始模型投影。P03 的 `revision.note` 是唯一预定后续请求，只有初稿独立质量审查合格后才可发送一次；这项后续内容不属于初始投影。

## 人工评分与停止边界

每个原子判分点在 `gold.json` 的 assertions 中给出 meaning 和原文 evidence。检查标题和正文全部声称，不限于已列出的片段；新增且无证据的声称也属于错误。应逐项检查对象范围、条件的“且/或”、数值、单位与分母、来源对应、日期和时点、待办/已执行/完成状态。不得因字面含有两个冲突值或一句“不确定”就忽略其后的无据裁定。

P01 的B档与门封闭是条件式，材料并未证明当时条件实际成立；不允许直接宣布已改地点。每人“最多2副”既不是必须领2副，也不提供总领取量。P03 的卡数不提供人数；材料没有规定旧卡号码不符者怎么处理，不把臆补这一分支当要求。初稿若提前完整加入材料中的真实办理提示，可以通过；修改阶段仍应检查预定格式和条件，不增加临时修改要求。

P02 的业务目标就是解释冲突，因此明确保留准确值未定是正确交付。P06 的目标是核验声称唯一最终数量的既定稿件，因此冲突仍未解决意味着该稿不得交付。两者不能混为一类“已罗列冲突即可通过”。P04 的空白不等于零，也不表示状况不变或已修复；封存的只是记录页。

四个生成任务只有应用终态 review、逐项人工质量审查合格、证据锚定成立且应有生命周期检查通过，才可列为“具备人工验收条件”。review本身不证明答案正确，脚本操作也不能冒充人工验收。P03 初稿错误即为业务失败，不发送预定修改来补救；只允许一次事先写定的修改。P04 两次重启应保留预期状态，首次重启不得派发模型，review处重启不得换稿或丢失核验依据。

两个固定负例必须逐字保持 candidate；不得替换成安全的新稿，再把新稿成功算作原稿通过。预期 blocked 表示错误稿被正确拦截，不代表其业务目标已完成。待处理、未决、无法判定、协议/传输故障和未运行项必须分别留痕，不能被归并为“零错误”。模型协议门检通过也不能替代六项业务质量判断。

## 原文锚点及离线复核

锚点只对 source.content 定位，不包含来源标题。`start` 包含、`end` 不包含，单位是 JavaScript UTF-16 code unit；`sourceHash` 为未经改写的 content 字符串按UTF-8编码的SHA-256。每个引文在本来源中唯一出现，`content.slice(start,end)` 必须与 quote 完全相同。断言涉及不同原文片段时分别给锚点，不拼接伪引文。

