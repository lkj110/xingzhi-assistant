# 冻结基础版验收执行器

本目录是评测工具，产品源码和安装包不变。配套样本为已经独立审核的 `../foundation-acceptance-20261028`，不改题、不更换金标准。Windows Foundation 0.42.4 的真实 EXE 经 renderer → IPC → Worker → 原 Codex 订阅适配器运行。临时 PATH 中的薄 CLI 转接程序只连随机 nonce 保护的 loopback 端点；实际模型边界前先做持久预算准入。固定反例单独在冻结 ASAR 的隔离 Worker 中一次初始化，后续不能改稿或接受。

## 离线预演

使用系统临时目录和全新 profile。`--offline` 不发现或运行官方 Codex CLI，不探测登录，不读取用户模型配置。它明确返回合成回复及用量；这些数字不能作为真实成本或幻觉率。完整预演覆盖门检、四个生成流程（含精确修改及两次冷启动）和两个固定错误稿。三项故障分别为错误外层 JSON、错误内层 JSON、未知用量，均须在门检停止且不追加格式修复调用。

```powershell
node --test evaluations/foundation-runner/*.test.cjs
node evaluations/foundation-runner/integration-test.cjs --executable <冻结EXE绝对路径> --output <全新输出目录绝对路径>
```

另有案例预算故障：仅在 offline 克隆预算中把 F01 阈值降至50000并同步总额度，验证首次生成后核验准入被拒绝、其余案例仍继续；封存计划和样本不改，live 不允许此注入。预演保留合成工作空间和原始审计，便于复核。无生产数据迁移、安装更新或真人验收。正例的公开验收快照必须 ready，负例不可 ready；脚本禁止 `accept` 与 `acceptanceAccept`。

## 真实执行前的准入

1. 准备包、执行器文件、调用和取消相关依赖、安装 EXE/ASAR 及 unpacked Windows helper 均须匹配封存；每次准入和重启复核。官方 CLI 另绑定获准运行时的可执行文件哈希。
2. 必须存在针对当前 runnerIdentity 的独立审核通过记录和新的用户预算批准。真实授权绑定唯一 runId、固定输出目录、样本/执行器身份、模型 CLI 哈希、36 次尝试及 700000 tokens 停止阈值，并明确接受非硬封顶限制。授权文件一次性原子消费，换输出目录或重复消费均拒绝。此目录不附真实授权文件。
3. 真实运行仅执行 `--live --authorization <批准记录> --real-cli <经核对的CLI>`。批准记录必须来自真实用户批准，不能由工具自行生成或把测试授权当真。首次调用开始后停止即结束本轮，不自动复跑或挪用历史额度。

每次应用尝试都计数，包括已证明未转发的本地拒绝。CLI exec、应用 modelCalls 和持久账本必须对账；未到转发边界的错误按可证实的零远端调用记录，已转发却无权威用量则总数未知。已知用量后的失败保留已知值；缓存缺失单列未知，不把 input+output 变成未知。原始 usage 事件、失败响应、错误详情和进程树退出证据保留。外层/内层 JSON 和必要应用协议在返回成功前检查；阻断隐式 JSON 修复及 revisionRecovery，合法读取续轮、预定修改、受控全文扩展仍计预算。

## 预算与结束

沿用拟申请的 36 次应用尝试、700000 input+output tokens 停止阈值：门检 4 次/100000、业务 32 次/600000。各级最后一个尝试槽保守留给本地拒绝，避免到限后发现拒绝本身成为额外一次；因此并不承诺全部额度都可转发。串行预留依旧为 CLI 输入 UTF-8 字节 + 实际外层 schema 字节 + 32768 输出余量 + 4096 封装余量。字节预留不是实际 token。

当前订阅 CLI 无本次可强制设置的单请求输出 token 上限。700000 是准入/停止阈值，**不是服务端硬上限**；在途请求仍可能超额，必须记录实际值并停止。未知/冲突用量、协议错误、宿主工具、冻结身份变化、全局预算拒绝或取消均停整轮；案例预算拒绝/业务不满足结束该例。应用内部未观测的 CLI 网络重试不等于应用调用次数。

门检及 F03 初稿先写独立内容检查点：只给审查者原文、要求和当前稿，不给系统是否通过；回执绑定 case、stage、内容及样本身份，不能写入模型上下文或业务状态。门检拒绝停整轮，F03 初稿不合格结束该例，保留初稿评分。无回执不默认通过。AI 独立检查不等于真人接受；四个正例最后仍待真人阅读并明确接受。45 分钟发起窗口从第一次尝试开始，不因 AI 检查点重置；每次请求 idle 2 分钟、total 3 分钟。

结果单版本、少量合成场景，只报告各项分子/分母和 N/A；不能据此宣称总体零幻觉、比历史试验省多少 token 或完整 Agent/macOS 已验收。正式主评测和平台公共模块抽取仍在范围外。
