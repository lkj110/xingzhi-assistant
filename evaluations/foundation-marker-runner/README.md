# 人工表达确认：独立候选验收执行器

仅为 `foundation-marker-acceptance-20261029` 和 ASAR `9fe3cc8…` 提供固定入口。产品、旧 runner、旧样本和安装版不修改。`--offline` 仅使用 loopback CLI 替身，不发现官方 CLI，不探测用户登录；合成用量不能用于成本或模型质量结论。`--live` 必须有当前样本及执行器独立审核、绑定唯一 runId/新输出目录/CLI 哈希/计划哈希的新用户预算批准，不附真实授权。

共享旧执行器的持久预算、授权、传输、短长路径保护、嵌套证据协议、固定错误稿 Worker。新 broker 只调整阶段准入、所有预算拒绝停整轮、达到阈值停止与迟到请求记账。checkpoint 单独增加修订要求绑定；不修改历史封存。执行器 seal 覆盖新文件、共享模块传递依赖以及 Playwright 运行库；样本 seal 包含输入投影和完整候选外层清单。每次启动复核全部包文件，每次发起复核核心包、样本、执行器及依赖。

## 真人边界

生成、严格核验、一次预定修改由执行器发起。每稿先输出独立内容检查点，只包含完整要求、原文、文稿和本阶段修订要求；审查回执不能进入模型上下文。实时 `independent-review-needed` 事件给出请求与回执路径。审查者必须与样本作者、代码实现者不同。

出现表达待确认时，执行器写出 `*-marker-confirmation.json` 并等待。用户在独立候选窗口阅读来源及文稿，点“确认这些表达已清楚”，再单独点“重新核验”。确认本身无模型调用；重检只允许核验，不能生成。每预定稿阶段至多一次，仍待确认即结束本轮。若自然未触发则报告未验证，不能改稿或改类型制造触发。

正例最后等待用户点击“验收完成”，观察 `completed`、`acceptedBy:user` 和稿件不变；不可用 AI 审核或脚本点击替代真人验收。live 分支没有调用确认/重检/接受的命令；模拟点击单独在只允许 offline 的模块。此边界约束执行器，不声称抵御同一电脑上另一个同权限脚本伪装用户。

等待期间每 200ms 读取状态，不发模型请求，不重置首尝试起 45 分钟窗口。整个窗口内未操作记 pending 后结束，不默认同意。用户可 Ctrl+C 或在输出目录创建 `STOP` 文件，执行器结束整轮；已在途调用保留实际/未知用量。UI 中修改要求、资料、文稿、提前接受或触发其他调用均结束本轮。只读取已确认的当前报告，确认不能清除独立拒绝或其他证据错误。

## 运行与结束

```powershell
node --test evaluations/foundation-marker-runner/*.test.cjs
node evaluations/foundation-marker-runner/run.cjs --offline --executable <独立候选EXE> --output <全新目录>
node evaluations/foundation-marker-runner/integration.cjs --executable <独立候选EXE> --output <全新目录>
```

输出目录只允许在仓库同级 `foundation-marker-runs-20261029` 内新建，禁止写进安装目录、候选包、源码或旧封存包。新 profile 通过现有“暂时跳过”按钮关闭首次引导，不授予系统权限。临时目录使用与既有固定错误稿 Worker 一致的 `fs.realpathSync`，避免混用 Windows 8.3 短路径与 native 长路径。

40 次应用尝试、80 万 input+output tokens 是待申请停止阈值，不是服务端硬封顶，在途请求可能超出。每例最后一次尝试留作本地拒绝记账；字节预留不等于真实 tokens。协议错误、未知/冲突用量、身份变化、任何预算拒绝或阈值到达、超时、非计划调用、错误放行、未闭环或用户停止均终止整轮。固定负例正确拦截属于预期结果。所有失败保留原始响应和用量，不自动修 JSON、不换样本、不追加调用。

结果含每稿初检快照、人工重检、预定修订、最终任务、调用/账本和人工等待记录。阶段成本由每条调用的 `evaluationPhase` 及权威 usage 求和；失败和本地拒绝同样计入。真实最终审核另按完整封存 gold 独立裁定：4 正例计划/已尝试完成率，初/终/放行稿幻觉率，合格稿硬误拦率、人工转交率、最终未放行率，2 固定负例错误放行率及错误生成稿放行率，各列分子/分母。技术失败、待人工、未执行与无法裁定单列 N/A，不当零错误；成本同时报告每个合格且真人验收任务。离线 summary 的 technicalPassed 只表示模拟链路通过，所有模型质量指标 N/A。
